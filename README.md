# Progress

Прототип переиспользуемого кругового индикатора для мобильных веб-приложений.
Реализован на HTML, CSS и чистом JavaScript, без сторонних библиотек,
фреймворков, шаблонизаторов и сборки.

## Запуск

Распакуйте архив и откройте `index.html` в браузере. Устанавливать зависимости
не требуется. Начальное значение — 60, Animate и Hide выключены.

Если используете VS Code, можно открыть папку проекта и запустить
`index.html` через Live Server.

Для запуска через локальный HTTP-сервер, если установлен Python:

```bash
python -m http.server 8000
```

В Windows вместо `python` при необходимости используйте `py`.
Приложение откроется по адресу <http://localhost:8000/>.

## Управление

| Элемент | Поведение |
| --- | --- |
| Value | Меняет прогресс от 0 до 100, включая дробные значения. |
| Animate | Включает непрерывное вращение по часовой стрелке. |
| Hide | Скрывает индикатор. Элементы управления остаются на своих местах. |

Значения меньше 0 ограничиваются нулём, больше 100 — сотней. Поле можно
временно очистить для ввода нового значения. Если оставить его пустым,
при потере фокуса вернётся последнее корректное значение.

В портретной ориентации индикатор расположен над настройками,
в альбомной — слева от них. При повороте состояние сохраняется.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `ozon-progress`.
2. Добавьте в корень репозитория содержимое папки проекта. `index.html`
   должен лежать непосредственно в корне, рядом с `progress.js` и CSS.
3. Сделайте коммит в ветку `main`.
4. Откройте **Settings → Pages** в репозитории.
5. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
7. После завершения публикации GitHub покажет адрес приложения. Откройте
   именно этот адрес на телефоне и проверьте поворот экрана.

Если загружаете файлы через сайт GitHub, используйте **Add file → Upload files**
и загрузите распакованные файлы проекта. ZIP-файл сам по себе приложением
на Pages не станет.

Подробности: [официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Использование компонента в другом приложении

Для самого индикатора нужны только `progress.js` и `progress.css`.
Компонент не обращается к полям управления и не зависит от стилей демостраницы.

```html
<link rel="stylesheet" href="./progress.css">
<div id="upload-progress"></div>
<script src="./progress.js"></script>
<script>
  const progress = new Progress(document.querySelector('#upload-progress'), {
    value: 25,
    animated: false,
    hidden: false,
    label: 'Загрузка файла',
  });

  progress.setValue(70);
  progress.setAnimated(true);
  progress.setHidden(false);
  progress.setState({ value: 100, animated: false });
</script>
```

### API

| Свойство или метод | Назначение |
| --- | --- |
| `new Progress(container, options)` | Создаёт индикатор внутри DOM-элемента. Все параметры `options` необязательны. |
| `setValue(number)` | Устанавливает прогресс. Принимает конечное число, ограничивает его диапазоном 0–100. |
| `setAnimated(boolean)` | Включает или выключает вращение. |
| `setHidden(boolean)` | Скрывает или показывает индикатор. |
| `setState({ value, animated, hidden })` | Обновляет переданные параметры, сохраняет остальные. |
| `value`, `animated`, `hidden` | Позволяют прочитать текущие параметры. |
| `state` | Возвращает отдельную копию текущего состояния. |
| `destroy()` | Удаляет только индикатор данного экземпляра. |

Методы `setValue`, `setAnimated`, `setHidden` и `setState` возвращают экземпляр,
поэтому их можно вызывать цепочкой. Неверные типы, NaN и Infinity вызывают
`TypeError`. Если в `setState` передан некорректный параметр, всё обновление
отменяется и прежнее состояние сохраняется.

Несколько экземпляров могут работать независимо. Параметры animated и hidden
независимы от value и друг от друга. Скрытый компонент принимает новые значения.
На время скрытия вращение приостанавливается.

### Настройка оформления

CSS-переменные можно задать на контейнере отдельного экземпляра:

```css
#upload-progress {
  --progress-size: 160px;
  --progress-color: #005bff;
  --progress-track-color: #edf2f5;
  --progress-duration: 2s;
  --progress-reduced-duration: 4s;
}
```

Стандартный диаметр — 120 px, период вращения — 1,4 секунды. При системной
настройке `prefers-reduced-motion` вращение замедляется до 4 секунд,
а переходы переключателей отключаются. Анимацию пользователь включает явно.

Индикатор имеет `role="progressbar"`, доступное имя и актуальный
`aria-valuenow`. Переключатели реализованы нативными checkbox с `role="switch"`,
поддерживают клавиатуру и имеют видимую рамку фокуса.

## Проверка

Откройте `/tests/` через локальный HTTP-сервер или GitHub Pages.
Проверки запускаются автоматически; вверху отображается результат.
Для повторного запуска обновите страницу. При открытии через `file://`
браузер может ограничить доступ тестов к вложенным страницам, поэтому
для тестов нужен HTTP-сервер.

Проверены 25 сценариев: API, границы диапазона, неправильные типы,
независимость состояний и экземпляров, ввод, скрытие, вращение,
поворот экрана и отсутствие переполнения в размерах
320 × 568, 568 × 320, 390 × 844, 844 × 390 и 280 × 400.

Синтаксис JavaScript при наличии Node.js можно проверить отдельно:

```bash
node --check progress.js
node --check app.js
node --check tests/progress.test.js
```
